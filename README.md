# Как устроен BTRFS

Анимированная презентация Артёма Кудякова на Motion Canvas.

[Смотреть презентацию](https://t3m8ch.ru/btrfs-slides/).

## Запуск

Установите зависимости командой `pnpm install`, затем запустите редактор:
`pnpm start`.

Статическая версия для хостинга собирается командой `pnpm build:site` в папку
`dist/`. Инструкции по развёртыванию — в [deploy/README.md](deploy/README.md).
